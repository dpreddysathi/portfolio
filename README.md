# portfolio-v2

Personal portfolio of **Sathi Durga Prasad Reddy** — Java Backend Developer.

React 18 + Vite + TypeScript, plain CSS (no UI framework). Dark
emerald-on-charcoal developer aesthetic, `// code-comment` section labels,
animated stats band, scroll-reveal animations, mobile-first with hamburger nav.

## Run

```bash
npm install
npm run dev      # local dev
npm run build    # production build -> dist/
```

## Deploy

GitHub Pages via `.github/workflows/pages.yml` (builds `dist/` on push to
`main`). Because the deploy token can't push workflow files, `pages.yml` is
committed separately and uploaded through the GitHub web UI instead.

Live: `https://dpreddysathi.github.io/portfolio-v2/`
